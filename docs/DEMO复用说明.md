## 4. 接入与验收

开发先复制所需静态贴图到新应用资源目录，保留manifest来源映射；资源压缩/改格式如需进行，另出衍生manifest与视觉对照，不能替换原始来源文件。DEMO目录不整体暴露到学生端，以免泄露旧玩法与开发内容。

在真实浏览器检查小车contain比例、四方向转动、金币字母标签、沙地与木障格线、1024×768布局、贴图白边/透明边缘。每张PNG已本地查看，但这不等于最终界面视觉验收；这一步待应用实现完成后进行。

DEMO源码是外观与控制参考，不是当前线上存档/UUID/全量埋点的既有实现。新增玩家码、输入区、确认弹窗、导航和所有动态控件都必须登记到交互清单；不要只给旧有keydown加一个track就宣称完成全量采集。
